# NoName.Science
Independent Science • Research • Technology • Open Knowledge  NoName.Science is an independent digital project exploring science, technology, emerging ideas, research, and open knowledge.
What is NoName.Science?

NoName.Science is a platform for collecting, organizing and presenting ideas, research materials, experiments, technologies and questions that deserve further investigation and discussion.
